Sell dogtags to Ref in exchange for GP coins!

Config includes:
  - Fine tune how much dogtags are worth in GP, default values has them increase in value by 1 Gp for every 7 levels, capping at 10 GP
  - Blocks dogtag sales to other traders, can turn off
  - Lega Medal barter at Ref 1, costs 100 GP, adjustable
  - Lega Medals can no longer be sold, only used in barters
